# 涨停回调四维打分系统：有效性验证与重构研究报告

**样本区间**：2020-01-01 ~ 2025-12-31（指标预热自2019-01-01）
**数据源**：本地 MySQL `stock_data.daily_kline`（通达信 .day 日线导入，未复权）
**研究工具**：Python (pandas / statsmodels / scikit-learn / LightGBM)
**报告日期**：2026-09-22

---

## 1. 摘要

本研究对用户提供的通达信"四维打分系统"（趋势40 + 形态30 + 关键位20 + 止损10，总分100）在2020–2025年A股数据上做了系统性有效性验证，并在验证结论基础上完成了逐项重构和机器学习权重学习。核心结论：

1. **原始公式未通过有效性验证**：总分与未来1–10日收益呈统计显著但经济量级很小的**负相关**（Fama-MacBeth斜率t值-3.3~-5.3，日度IC约-0.008），六年中每一年方向一致。占70分权重的趋势分与关键位分是负贡献来源；唯一正向的分项是权重最小的止损分。
2. **数据层面发现两类会颠覆结论的污染**：数据库混入指数/ETF/可转债/回购等非股票代码（曾造成+429,900%的假"日收益"）；未复权价的除权跳变与跨停牌窗口造成假极端收益。建立了一套清洗规则后所有结论才可信。
3. **用户的三个形态学直觉经数据检验，部分成立、部分相反**：
   - "收盘贴近最高价"成立（5–10日RankIC +0.04~+0.05）；"今日最高价创新高"单独无增量信息，且大幅新高(>5%)有害；
   - "横盘→涨停→十字星"**四分之三被证伪**：板前横盘、封死板、十字星均为负向信号；唯一强有效部件是**缩量**（RankIC +0.06~+0.07，全体系最强单因子之一）；
   - "回踩EMA20收盘在其上"方向正确但不彻底：**收盘相对EMA20的偏离度越低越好，收破EMA20反而是最优组**（涨停后窗口内均值回归主导）。
4. **重构后的手工公式（V3体系）由负转正**：主板口径下总分窗口内RankIC +0.090~+0.094（t≈28~30），六年每年显著；场景（涨停后1–3天）常规月份70–89分档 fwd5 +0.97%~+1.57%、胜率53%~63%。
5. **机器学习学权重再提升约60%**：walk-forward纯样本外（2022–2025）日度RankIC达 +0.166(LGB)/+0.171(Ridge)，且线性模型与树模型几乎打平（可翻译回通达信公式）。ML最大价值是**排雷**（最低十分位5日平均-3.78%）与**给手工候选池做过滤**。
6. **推荐落地配方**：手工V3公式出候选（总分70–89、涨停后1–3天优先），ML分数过滤掉当日截面后50%。样本外常规月份口径：fwd5 +0.61%、fwd10 +1.05%、胜率50.5%/51.8%，日均约6只候选。

## 2. 研究背景与目标

用户提供了一个用于"涨停后回调"场景的通达信副图打分公式（含四维得分、当日异动标记、昨日涨停标记），希望用本地数据库中2020–2025年数据、以线性回归为主验证其有效性，并根据验证结果迭代改进。

研究目标：

1. 忠实复刻公式（保持通达信语义），量化其对短期（1–10日）收益的预测能力；
2. 定位无效/反向的部件，用数据驱动方式重构；
3. 用机器学习替代手工权重，并给出可落地的使用方式；
4. 全程保证方法学严谨：样本外验证、崩溃月稳健性、年度稳定性、绝对收益与相对排序分开陈述。

## 3. 数据与预处理

### 3.1 数据源

- MySQL `stock_data.daily_kline`（本机），由用户脚本自通达信 `vipdoc` 目录 `.day` 文件导入：ts_code、trade_date、OHLC、volume、amount；价格为**未复权**价（元，2位小数），成交量单位股。
- 读取范围 2019-01-01 ~ 2025-12-31，共 **13,425,384** 行，本地缓存为 `kline_2019_2025.parquet`（239MB），复跑单轮全量计算约1.5–4分钟。
- 辅助表 `stock_info`（含当前股票名称）用于ST识别。

### 3.2 发现的数据质量问题

### 3.3 清洗规则（最终口径）

1. **股票池白名单**：仅保留沪深A股股票代码；最终研究口径进一步收紧为**10cm主板**（600/601/603/605.SH，000/001/002/003.SZ），剔除创业板(300/301/302)、科创板(688/689)、北交所——与公式涨停定义1.098的制度口径一致。白名单后代码数：全A股5,397只 → 主板3,366只。
2. **剔除ST**：双层过滤——① `stock_info.name` 含"ST/退"（当前快照，剔除188只）；② **数据驱动历史ST时段**：滚动120交易日内 max|日涨跌| ≤ 6.8% 且 |日涨跌|∈[4.4%, 6.5%] 出现≥3次（5%板特征）。②共标记344,537行（占主板7.02%）；注：该方法会误伤部分"非ST但走势平静"时段，剔除前后所有指标几乎不变，不影响结论。
3. **剔除上市一年内新股**：个股数据内K线序号 pos ≥ 240（约一年；数据库无上市日期字段，以K线数近似）。
4. **未来收益窗口清洗**：窗口内相邻K线间隔>7自然日（跨长期停牌）→ 收益置缺失；当日跳空跌幅超板幅（主板-10.5%）→ 疑似除权/坏数据，整行剔除（主板口径3,107行）。
5. **缩尾**：回归与分组统计用的未来收益按**日横截面1%/99% winsorize**；中位数与胜率不受缩尾影响，一并报告。
6. **打分指标层面**：NaN参与比较一律为False（与通达信一致）；从未出现涨停的个股（BARSLAST无定义）剔出样本。

## 4. 研究方法

### 4.1 公式复刻

逐行复刻通达信语义并抽样人工核对（以000001.SZ 2020-07-06涨停段为算例核对了ZT_BAR、ZT_H/ZT_L、RANGE_H/L、ZT_COST、四个分项与总分）。关键语义处理：

- `BARSLAST(ZT)`：以涨停日为段首做分段（segment）实现，段内逐日+1；
- `HHV(H, ZT_BAR)`/`LLV(L, ZT_BAR)`（变周期）：数学上等价于"上一涨停日之后至当日"的累计最大/最小值，用分段cummax/cummin精确实现；
- `COUNT(ZT, ZT_BAR-1)>0`（HAS_ZT_IN_RANGE）：**恒为False**——由BARSLAST定义，窗口内不可能再有涨停，原公式该条件为死代码；
- `REF(X, ZT_BAR)`：段首值广播；`EMA`：ewm(adjust=False)；等值比较（如LLV(L,3)=REF(L,2)）保留精确比较（价格2位小数）。

### 4.2 检验方法

- **Fama-MacBeth逐日横截面回归**：每日以未来N日收益对分数做OLS，汇总斜率均值、t值（均值/标准误）、斜率>0天数占比；多变量版每日同时回归四个分项以看边际贡献。
- **IC / RankIC**：每日截面上分数与未来收益的Pearson/Spearman相关，报告均值、t值、ICIR及年度分解。
- **分档统计**：分数分段 → 未来收益均值/**中位数**/胜率（三者并报，防止均值被右尾欺骗）。
- **评估期限**：fwd1 / fwd2 / fwd3 / fwd5 / fwd10（收盘-收盘）。
- **窗口内评估原则**：形态/关键位等窗口限定因子必须在"涨停后1–8天"样本内做FM——全样本回归会把"是否刚涨停"的人群混杂（涨停后整体负漂移）误计入因子方向。这是本研究方法论上最重要的一处修正。

### 4.3 稳健性设计

- **崩溃月剔除**：2024-02（微盘股流动性危机）、2024-09/10（924行情暴涨暴跌）为系统性事件簇；所有关键结论均报告"含/剔崩溃月"两个口径。诊断中确认了一个"低分口袋5日+2.4%"完全由该事件簇驱动（58.5%集中于2024-10），不可作为可重复形态。
- **年度分解**：六年（OOS为四年）逐年RankIC，拒绝单年驱动。
- **绝对/相对分离**：明确区分"排序能力"（RankIC，稳定）与"头部绝对收益"（依赖市场环境）。

## 5. 原始公式验证：未通过

### 5.1 总量结果（全A样本，642万行，清洗后）

| 期限  | FM平均斜率 | t值            | 日度IC  | IC t值 | RankIC  |
| ----- | ---------- | -------------- | ------- | ------ | ------- |
| fwd1  | -0.00002   | **-3.3** | -0.0073 | -3.2   | -0.0086 |
| fwd5  | -0.00005   | **-5.3** | -0.0083 | -3.8   | -0.0027 |
| fwd10 | -0.00004   | -2.8           | -0.0021 | -1.0   | +0.0042 |

总分越高，未来收益越低；2020–2025每一年fwd1斜率均为负。"极品(≥90)"档六年仅232个样本（0.004%），无统计意义。

### 5.2 分项拆解（fwd5多变量FM）

| 分项     | 名义权重 | 斜率t值               | 判决                                                       |
| -------- | -------- | --------------------- | ---------------------------------------------------------- |
| 趋势分   | 40       | -4.3 ~ -6.8           | **显著负向**（"四价连续抬高"=短期过热，A股反转效应） |
| 形态分   | 30       | +0.1 ~ +1.1           | 无效                                                       |
| 关键位分 | 20       | -1.5 ~ -5.1           | 负向                                                       |
| 止损分   | 10       | **+4.9 ~ +9.3** | **唯一正向**（本质是"贴近支撑的低吸"因子）           |

70%权重押在负alpha信号上、唯一正alpha分项权重最小——总分负向的结构性原因。

### 5.3 场景细分

公式在其设计场景内（涨停后1–3天）有微弱正向排序能力（组内IC +0.02~+0.035），但：① 涨停后次日整体平均收益为负（-0.39%/日，-1.10%/5日）；② 离涨停4天以后彻底失效。**原公式只有"涨停后极短窗口内相对排序"这一点残值。**

### 5.4 趋势分档位实证（重构依据）

- 场景内旧趋势分档位呈**倒U**：30分档最好（fwd5 -0.38%），条件最苛刻的40分档（8项全抬高）反而更差（-0.65%）——"极致连升"是过热信号，档位给反；
- 10分档（"探底回升"）是全体系最差单档之一：fwd5 -1.73%、胜率36.7%——涨停回调中"未创新低+收盘高于2日前"捕捉的是弱势假企稳。

## 6. 分项重构

### 6.1 趋势分：V2 → V2.2（用户新定义 + 数据修正）

**用户新定义**："当日收盘价离最高价越近、今日最高价比昨天最高价高 → 趋势分越高"。

**部件检验**（窗口样本60万行）：

| 部件                       | 结论                                                         | 证据                                                                     |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| PROX = C/H（收盘贴近日高） | **显著正向**，期限越长越强                             | FM RankIC：fwd5 +0.042(t=11.7)，fwd10 +0.052(t=14.5)                     |
| NH = H/REF(H,1)-1（新高）  | 单独无增量（双变量斜率≈0）；**大幅新高(>5%)显著有害** | 新高>5%组 fwd5：主样本-0.45%，场景内-1.36%、胜率38.7%；温和新高0–2%最佳 |
| 例外                       | PROX≈1.000（精确收在最高点、多为冲板未遂）单独看最差        | 场景内fwd1 -0.87%、胜率37.7%                                             |

**版本迭代**：V2按用户定义归档（新高×贴近度）→ 发现"新高但收盘回撤>6%（长上影）"档实测最差，V2.1将其10分→0分 → V2.2对"新高幅度>5%"封顶10分。

**V2.2定义（40分制）**：

```
TREND_RAW := 新高时: PROX>=0.99→40 | >=0.97→30 | >=0.94→20 | 长上影→0
             未新高: PROX>=0.97→5 | 其余→0
TREND_V22 := IF(NH>0.05, MIN(TREND_RAW,10), TREND_RAW)
```

**效果**：换上V2.2后总分FM由显著负转正（fwd5 RankIC +0.020, t=8.4；fwd10 +0.028, t=11.6）；场景内40分档 fwd5 +0.57%（旧版40分档 -0.65%）。

### 6.2 形态分："横盘→涨停→十字星"假设检验 → V3

**用户假设**："前一段时间波动不大，一直横盘，然后涨停，之后十字星，这种形态最好"。量化为五个部件分别检验（窗口样本，清洗后）：

| 部件                      | 用户直觉 | 数据判决                                  | 证据（fwd5均值）                                                                       |
| ------------------------- | -------- | ----------------------------------------- | -------------------------------------------------------------------------------------- |
| 板前横盘（PRE_AMP10小）   | 越好     | **❌ 相反，单调**                   | 振幅≤8%组 -0.30% vs >35%组**+0.49%**                                            |
| 涨停封死板（SEAL）        | 越好     | **❌ 相反**                         | 封死板 -0.50%/胜率42.8% vs 炸板未封**+0.49%**/48.5%（主板未封板fwd10 +1.40%）    |
| 之后十字星（DOJI小）      | 越好     | **❌ 相反，单调**                   | 十字星档 -0.36% vs 大实体档**+0.004~+0.22%**；阴阳拆分后"大实体阴线（洗盘）"最佳 |
| 板日温和放量（ZT_VRATIO） | 部分对   | **✅ 倒U确认**                      | 1–2倍最佳(-0.06%)；缩量板(<1倍)-0.45%、天量板(>6倍)-0.84%                             |
| 缩量整理（V_VS_ZT小）     | （隐含） | **✅ 强验证，全体系最强单因子之一** | <0.3倍 +0.32% vs >2.0倍**-1.47%**，严格单调；RankIC +0.061~+0.074 (t=25~30)     |

**重要诊断**：按用户直觉组装的第一版形态分（横盘10+板质8+星线12）实测为**强负向**（RankIC -0.047~-0.071）；其中出现一个fwd5 +2.4%、胜率62%的异常低分口袋，查明为**2024-02/2024-09-10系统性崩盘后的"缩量深跌企稳"事件簇**（58.5%集中于2024-10），属市场级择时现象，不可作为个股形态重复利用。

**V3定义（30分制，窗口1–8天，窗外0分）**：

```
A 缩量分(0-14):  V_VS_ZT <=0.3→14 | <=0.5→12 | <=0.8→8 | <=1.2→4 | >1.2→0
B 板前活跃(0-8): PRE_AMP10 >0.35→8 | >0.20→5 | >0.13→3 | 横盘→0   (与直觉相反)
C 板日量比(0-8): ZT_VRATIO 1-2→8 | 2-3.5→5 | 3.5-6→2 | 缩量板/天量板→0
```

**效果**（窗口内FM）：RankIC fwd1 +0.039、fwd5 +0.022；剔崩溃月几乎不变；分档单调（0-7档 fwd5 -1.15% → 24-30档 +0.91%/胜率51.1%，剔崩溃后高档+0.2~+0.3pp相对优势保持）。

### 6.3 关键位分："回踩EMA20收回其上"假设检验 → V3

**用户假设**："回踩EMA20、收盘价在EMA20上"最好。部件检验（窗口样本）：

| 组                             | fwd5均值          | 胜率            |
| ------------------------------ | ----------------- | --------------- |
| 未触及EMA20+收盘上（悬空强势） | -0.571%           | 42.2%           |
| 触及且收回（用户形态）         | -0.334%           | 44.9%           |
| **触及但收破EMA20**      | **+0.870%** | **50.7%** |

- 收盘偏离度 DEV20=C/EMA20-1 **严格单调**：<0收破 +0.87% → 0-1% +0.09% → 5-8% -0.23% → >15% **-1.84%**（胜率52%→36%）；
- 其中收破组的正收益集中于深破>5%子组（+1.42%、胜率53.8%），且剔除崩溃月后仍为正（+0.28%、胜率47.7%）——**涨停后窗口内均值回归（低吸）主导，而非追强**；这与原公式中"止损分是唯一正向分项"的发现内在一致（止损分本质是粗糙的深回踩代理）。

**版本对比**（窗口内RankIC，fwd5/fwd10）：

| 版本                         | 定义                                       | RankIC fwd5             | fwd10                   |
| ---------------------------- | ------------------------------------------ | ----------------------- | ----------------------- |
| KEY_V2（用户定义）           | 击穿收回20/贴近回踩15/上方小偏离10/中偏离5 | +0.048                  | +0.046                  |
| KEY_V2b（混合）              | 收破单列12分                               | +0.093                  | +0.095                  |

## 7. 机器学习学权重

### 7.1 协议

- **样本域**：主板窗口样本348,008行（与手工公式同域，直接可比）；
- **特征（26个，全部收盘时点可得）**：四个手工分项 + 原始连续特征（PROX、NH、R1、R5、当日振幅AMPL、DOJI、阴阳、GAP_OPEN、DEV13、DEV20、EMA20斜率、HOLD、V_VS_ZT、V_VS_MA5、PRE_AMP10、ZT_VRATIO、SEAL、板后振幅AMP、ZT_COST、区间位置POS_IN_RANGE、对数成交额LOG_AMT、ZT_BAR）；
- **目标**：fwd5按日横截面去均值（学相对排序）；
- **walk-forward**：测试年Y∈{2022..2025}，训练=2020..Y-1，**全部样本外**；
- **模型**：Ridge(α=10，标准化+中位数插补) 与 LightGBM(350树, lr=0.06, num_leaves=31)。

### 7.2 样本外结果

| 模型               | fwd1 RankIC   | fwd5 RankIC   | fwd10 RankIC  | fwd5年度(2022→2025)   |
| ------------------ | ------------- | ------------- | ------------- | ---------------------- |
| **LightGBM** | +0.147 (t=36) | +0.166 (t=43) | +0.177 (t=46) | +0.140→+0.181，全显著 |
| **Ridge**    | +0.150        | +0.171        | +0.182        | +0.151→+0.169，全显著 |
| 手工TOTAL_FINAL    | +0.083        | +0.104        | +0.114        | +0.087→+0.122         |
| KEY_V3单因子       | +0.117        | +0.145        | +0.162        | —                     |

- ML约为手工总分的**1.6倍**排序能力；剔崩溃月不变；93%交易日IC为正；
- **Ridge≈LGB**：可学结构基本线性 → 学出的权重可翻译为通达信线性公式（已导出）；
- **LGB十分位严格单调**：D1 fwd5 **-3.78%**（胜率30.5%）→ D10 **+0.95%**（52.4%）——ML最大价值在**排雷**。

### 7.3 头部篮子悖论与组合策略（OOS 2022-2025）

| 策略                            | 日均只数            | fwd5均%（剔崩溃月）     | fwd5胜率                | fwd10均%（剔崩溃）      |
| ------------------------------- | ------------------- | ----------------------- | ----------------------- | ----------------------- |
| LGB前10%单独买                  | 24.6                | +0.27 (+0.04)           | 47.0%                   | +0.49 (-0.09)           |
| 手工70-89单独                   | 11.1                | +0.87 (+0.18)           | 51.8% (47.7%)           | +1.43 (+0.47)           |
| **手工70-89 ∩ LGB前50%** | **6.7 (6.0)** | **+1.22 (+0.61)** | **54.3% (50.5%)** | **+1.79 (+1.05)** |
| KEY_V3=20 ∩ LGB前50%           | 34.2                | +0.61 (+0.20)           | 50.4%                   | +0.98 (+0.40)           |

**结论：ML高分头部单独买不赚钱（涨停后人群负漂移+头部噪声），最优配方 = 手工规则出候选 × ML截面过滤。**

### 7.4 学到的权重

- **LGB增益重要性前列**：当日振幅AMPL 8.9%、板前5日涨幅ZT_COST 8.8%、板前10日振幅PRE_AMP10 8.2%、板日量比ZT_VRATIO 7.7%、对数成交额LOG_AMT 6.4%、当日涨幅R1 5.6%——模型自主发掘了量能/振幅/流动性结构；
- **Ridge符号4折全稳定的主要权重**：DEV13(-)、AMPL(-)、HOLD(+)、R1(+)、GAP_OPEN(+)、V_VS_MA5(-)、V_VS_ZT(-)、ZT_VRATIO(-)、SL_SCORE(+)——"离EMA13远=危险、大振幅=危险、缩量=安全、温和强势=安全"；
- **共线性警示**：KEY_V3、R5等系数符号跨折不稳定（与DEV13/DEV20等强共线），单个系数不可过度解读，应以整体公式与OOS指标为准。

## 8. 最终交付与建议使用方式

### 8.1 手工公式版（通达信，V3体系）

```
{==== 数据化四维打分 V3  总分100 | 适用: 主板10cm, 剔ST, 剔上市一年内新股 ====}
ZT:=C/REF(C,1)>=1.098;
ZT_BAR:=BARSLAST(ZT);
INWIN:=ZT_BAR>=1 AND ZT_BAR<=8;
EMA20:=EMA(C,20);

{1.趋势分40: 创新高+收盘贴近日高; 大幅新高>5%封顶10}
PROX:=C/H;
NH:=H/REF(H,1)-1;
TR:=IF(H>REF(H,1),IF(PROX>=0.99,40,IF(PROX>=0.97,30,IF(PROX>=0.94,20,0))),
     IF(PROX>=0.97,5,0));
TREND_SCORE:=IF(NH>0.05,MIN(TR,10),TR);

{2.形态分30: 缩量14+板前活跃8+板日量比8}
VV:=V/REF(V,ZT_BAR);
PRE_AMP:=REF(HHV(H,10)/LLV(L,10)-1,ZT_BAR+1);
ZT_VR:=REF(V/REF(MA(V,5),1),ZT_BAR);
A:=IF(VV<=0.3,14,IF(VV<=0.5,12,IF(VV<=0.8,8,IF(VV<=1.2,4,0))));
B:=IF(PRE_AMP>0.35,8,IF(PRE_AMP>0.20,5,IF(PRE_AMP>0.13,3,0)));
C1:=IF(ZT_VR>=1 AND ZT_VR<=2,8,IF(ZT_VR>2 AND ZT_VR<=3.5,5,IF(ZT_VR>3.5 AND ZT_VR<=6,2,0)));
SHAPE_SCORE:=IF(INWIN,A+B+C1,0);

{3.关键位分20: 收盘相对EMA20偏离度, 越低越好, 收破最高分}
DEV20:=C/EMA20-1;
KEY_SCORE:=IF(INWIN,IF(DEV20<0,20,IF(DEV20<=0.01,18,IF(DEV20<=0.03,15,
    IF(DEV20<=0.05,11,IF(DEV20<=0.08,6,IF(DEV20<=0.15,2,0)))))),0);

{4.止损分10: 原版保留(多变量下冗余, 可置0)}
ZT_L:=REF(L,ZT_BAR);
SL_PCT:=(C-MIN(ZT_L,EMA20))/C;
SL_SCORE:=IF(ZT_BAR>0,IF(SL_PCT<=0.03,10,IF(SL_PCT<=0.05,7,IF(SL_PCT<=0.08,4,IF(SL_PCT<=0.12,1,0)))),0);

TOTAL:=TREND_SCORE+SHAPE_SCORE+KEY_SCORE+SL_SCORE;

{股票池与信号}
主板:=CODELIKE('60') OR CODELIKE('00');
非ST:=NAMEINCLUDE('ST')=0 AND NAMEINCLUDE('退')=0;
满一年:=BARSCOUNT(C)>=240;
买入候选:=主板 AND 非ST AND 满一年 AND TOTAL>=70 AND TOTAL<=89
          AND ZT_BAR>=1 AND ZT_BAR<=3;   {1-3天信号质量最高; 放宽至8天量更大}
```

### 8.2 ML增强版

- `output/tdx_ml_formula.txt`：26项Ridge线性总分通达信公式（含基础定义，可整体粘贴；输出≈预测5日相对收益×10000，仅用于当日截面排序）；
- Python管道（`ML学权重.py` + `ML组合测试.py`，样本缓存 `ml_sample.parquet`）：可产出LGB分数（性能略优于线性版），用于每日候选过滤；建议**每年滚动重训**；
- **推荐执行流程**：手工公式筛 `70≤TOTAL≤89 且 ZT_BAR≤3` → 按ML分数取当日截面前50% → 持有5–10天。OOS常规月份期望：fwd5 +0.61%、fwd10 +1.05%、胜率50–52%，日均约6只。

## 9. 局限与风险提示

1. **价格未复权**：除权用"超板幅跳变"规则近似剔除，中度送转（如10送2~4，20cm板内）与小比例分红仍有残余噪声；建议后续接入复权因子（CSMAR通道可用）复核。
2. **ST识别为近似**：名称是当前快照；数据驱动法按行为识别历史时段但会误伤平静期非ST股（误伤方向保守，不影响结论，但样本略损失）。
3. **收盘口径 vs 实盘成交**：所有收益为当日收盘→未来收盘。涨停后候选次日常高开，**实盘需以次日开盘/盘中可成交价重估**，alpha将打折扣；未计手续费、滑点、冲击成本。
4. **绝对收益依赖市场环境**：涨停后人群整体负漂移；高分档常规年份绝对收益温和（+0.1~+1.0%/5日），2024类V反年份显著放大。本系统本质是**相对排序器+排雷器**，不是择时信号。
5. **信号稀疏**：场景口径（1–3天）日均候选仅0.6~6只（是否叠加ML过滤），适合作为雷达/候选池而非满仓策略；胜率50–66%意味着必须接受亏损单，靠右尾盈利。
6. **90+分矛盾档**：手工总分≥90为内部矛盾组合（收破EMA20却创新高收贴日高），实证为负，必须在规则层排除。
7. **模型时效**：ML权重基于2020–2025学习，市场风格切换（如涨跌幅制度、量化生态变化）会衰减；需滚动重训并持续监控OOS RankIC。
8. **多重检验风险**：本研究迭代了多个版本（V2/V2.1/V2.2/V3…），存在选择偏差可能；缓解手段是全部关键结论均通过崩溃月剔除、年度分解、窗口内口径三重稳健性检查，且ML为纯样本外。

## 10. 下一步工作建议

1. **含成本正式回测**（优先级最高）：手工∩ML组合，次日开盘价成交、双边千1.5费用+滑点、持有5/10日、对比主板等权基准，输出年化/最大回撤/夏普/换手；
2. **每日候选生成器**：定时读MySQL → 增量计算 → 输出当日候选清单（手工分+ML分+关键特征），落地为日常工具；
3. **止损分权重清零重标定**（90分制）与关键位/形态的连续化（去掉档位损失）；
4. **复权因子接入**后复核全部关键数字；
5. **20cm板单独标定**：当前V3体系按主板标定，创业板/科创板涨停定义与板幅不同，需单独重验后使用；
6. 探索**持有期优化**（fwd10 RankIC>fwd5，可能支持更长持有）与**卖出规则**（如按ML分数衰减止盈止损）。
